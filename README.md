Les dépôts privés : outils de poste, applications desktop livrées, serveurs MCP,
bots, pipelines audio et vidéo. La bannière ne les compte pas à part : elle donne
le total et ce qui est visible, la soustraction est vite faite. Les deux chiffres
sont relevés sur l'API, pas écrits à la main.

Ce compte n'est pas une vitrine. C'est un atelier fermé dont on aperçoit
la porte.
