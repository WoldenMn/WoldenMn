# Sécurité

Ce dépôt génère la bannière et le README du profil GitHub de WoldenMn. Il ne
tourne nulle part : un script Python écrit un SVG, deux scripts PowerShell le
régénèrent et l'exportent en PNG sur le poste de son propriétaire.

## Signaler une faille

Ne pas ouvrir de ticket public. Passer par le signalement privé de GitHub :
onglet **Security** du dépôt, puis **Report a vulnerability**
(<https://github.com/WoldenMn/WoldenMn/security/advisories/new>).

Décrire ce qui est touché, les étapes pour reproduire et l'effet obtenu.

## Versions prises en charge

Seule la dernière version publiée reçoit des correctifs.
